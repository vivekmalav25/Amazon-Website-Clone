# Amazon Website Clone
A front-end clone of the Amazon homepage built using **HTML5** and **CSS3**. This project replicates the layout and design of Amazon's landing page to practice modern web development concepts such as Flexbox, responsive layouts, and UI design.

## Features

- Amazon-inspired navigation bar
- Search bar with category dropdown
- Hero banner section
- Product cards with images
- Multi-section layout
- Footer similar to Amazon
- Hover effects for interactive elements

## Technologies Used

- HTML5
- CSS3
- Font Awesome

## Project Structure

```
Amazon-Website-Clone/
│── images/
│── index.html
│── Style.css
└── README.md
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/vivekmalav25/Amazon-Website-Clone.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
